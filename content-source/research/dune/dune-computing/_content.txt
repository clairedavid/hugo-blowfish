== PAGE HEADING ==
DUNE Computing: new training, a glossary, and R&D on columnar data analysis

== TEXT ==
As part of the Computing Consortium, I co-convened the Training and Documentation subgroup. We redesigned the onboarding and co-organized three tutorial sessions to help newcomers grasp the DUNE analysis workflow. The tutorials focused mostly on LArSoft, the software framework for event generation, detector simulation and reconstruction used to analyze data from Liquid Argon Time Projection Chambers (LArTPCs). I also modernized the DUNE Computing wiki, and designed and deployed DUNE's automated glossary.

My team led the first R&D on an interactive analysis facility for DUNE using columnar computing. This was done using the Coffea Python toolkit, a prototype package to supply high-energy collider physics (HEP) experiments with big-data technologies for physics analyses.
